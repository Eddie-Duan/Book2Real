# 接缝验收指标、失败码与校准

`qa_seams.py` **按接缝类型分别验收**，不是一把 SSIM 量到底。原因很直接：硬切本来就该"不像"，拿 SSIM 卡它只会逼你把片子做成叠化合集。

## 1. 取帧规则

每段取四帧：第 0、1、倒数第 2、最后 1 帧。

- `out` = 上段最后 1 帧；`prev_out` = 上段倒数第 2 帧 → 出点速度矢量。
- `in` = 下段第 0 帧；`next_in` = 下段第 1 帧 → 入点速度矢量。

`clips/seg_###/` 帧目录也支持（至少 4 帧），方便没有 ffmpeg 时先跑通流程。

## 2. 分类门禁

### CONTINUOUS（含合并页内部接缝）

| 指标 | 阈值 | 失败码 |
| :--- | :--- | :--- |
| 与目标关键帧 `SSIM` | ≥ 0.88 | `SEAM_MISMATCH` |
| `pHash` 汉明距离 | ≤ 6 | `SEAM_MISMATCH` |
| 全段时间漂移（DINOv2/代理余弦，最低帧） | ≥ 0.78 | `MORPH_RISK` |

合并页接缝直接与 `last_frame` 指向的 `clean_keyframe.png` 比：生成视频的最后一帧必须真的到达第二页。到不了就是模型没走完，换 seed 重跑该段，**不要**去改接缝类型。

### HARD_CUT

| 指标 | 阈值 | 失败码 |
| :--- | :--- | :--- |
| 亮度跳变 | ≤ 0.18 | `FLASH_FRAME_ERROR` |
| 屏幕方向点积 | ≥ -0.05（不反转） | `AXIS_FLIP_180` |
| 出点是否在速度峰值 ±2 帧（声明 `CUT_ON_ACTION` 时） | 是 | `ACTION_PEAK_MISS` |

硬切的"自然"靠**动机**，不靠相似度。所以这里只拦两件真会穿帮的事：闪帧、方向反转。

### MATCH_CUT

| 指标 | 阈值 | 失败码 |
| :--- | :--- | :--- |
| 切点两侧边缘轮廓 IoU | ≥ 0.60 | `MATCH_CUT_FAIL` |

比的是形态，不是颜色。形状对上了，观众才会"看见"那个呼应。

### DESIGNED_TRANSITION（`SHARED_T`）

| 指标 | 阈值 | 失败码 |
| :--- | :--- | :--- |
| 两侧到 T 的 `SSIM` | ≥ 0.85（主判据） | `BRIDGE_T_MISS` |
| 跨 T 的速度夹角 | > 60° 记 `warning: VELOCITY_MISMATCH_AT_T` | 不判失败 |
| 无 T 资产时退回：接缝 `SSIM` ≥ 0.88 且夹角 ≤ 45° | — | `BRIDGE_T_MISS` |

**为什么位置优先**：两侧都精确落在同一张 T 上时，切点是零位移的，接缝不可能"跳"。速度方向不一致是下一层问题（甩镜甩反了会别扭），但它不该把一条位置完美的接缝判死。第一版把它当硬门禁，结果把正确的接缝误杀——这是本项目的实测教训。

### BRIDGE_CLIP

| 指标 | 阈值 | 失败码 |
| :--- | :--- | :--- |
| 成片保留时长 | 1.0–2.0s | `BRIDGE_DURATION_ERR` |
| 与相邻场景色彩巴氏距离 | ≤ 0.25 | `BRIDGE_STYLE_DRIFT` |

## 3. 返修动作（单段隔离）

| 失败码 | 动作 |
| :--- | :--- |
| `SEAM_MISMATCH` | 换 seed 重跑该段；连续 2 次失败考虑改判 `HARD_CUT` |
| `MORPH_RISK` | 5s → 10s；已 10s 则缩短动作弧或改判硬切 |
| `FLASH_FRAME_ERROR` | 检查出点/入点是否一个过曝一个压暗；调整提示词光位描述 |
| `AXIS_FLIP_180` | 重生成入点段，锁定屏幕方向 |
| `ACTION_PEAK_MISS` | 切点前后移 ±2 帧；或改判普通硬切（不再声称动作切） |
| `MATCH_CUT_FAIL` | 提示词里锁定匹配物归一化坐标后重跑；仍不达标降级黑场 |
| `BRIDGE_T_MISS` | **只重跑未抵达 T 的那一侧**，另一侧不动 |
| `VELOCITY_MISMATCH_AT_T` | 不返修；若观感确实别扭，在 T 处补 0.1–0.2s 方向模糊 |

单段返修上限 3 次。超过就停，改判接缝类型或找上游换关键帧——继续烧钱换 seed 是在赌。

## 4. 校准（10 组样页）

初值来自一般水彩/平涂绘本。换画风（极简线条、拼贴、厚涂）前先校准：

```bash
python scripts/plan_scenes.py --calibrate --pages-dir ./calib_10 --out-dir ./calib_out
```

输出 7 项指标的 P10/P50/P90。标定法：

1. **4 组**同场景同机位：看 `feature_distance` 的 P90，作为"连续"的上限。
2. **3 组**同场景换景别：看 `scale_area_ratio` 与 `subject_shift_pct`，确认景别递进能被打出来。
3. **3 组**跨场景：看 `feature_distance` 的 P10，作为"跳变"的下界。

若"连续上限"与"跳变下界"重叠，说明这批画风的视觉轴不辨场景——此时**优先信 `scene_tag` 元数据**，并在 `NOTES.md` 记一笔。这才是诚实的做法，而不是硬调一个能跑通样例的阈值。

## 5. 阈值从哪里来

- `0.88 / 0.92`：与 relay-producer 的接缝门禁一致，保持全链路一套数。
- `pHash ≤ 6`：64 bit 感知哈希，6 bit 以内是人眼认为"同一张图"的经验界。
- `0.35 / 0.25 / [0.67,1.50] / 0.90 / 0.15`：在合成样页 + 通用插画分布上取的保守值，偏严（宁可多切一刀，不愿多融一次）。
- `IoU 0.60`：两个形状要能"对上"，重叠度低于 0.6 观众不会产生匹配感。
- `夹角 45° / 60°`：45° 是"方向大致一致"，60° 是"明显不一致但仍可接受"的分界。

这些数不是真理，是**可复算的起点**。改任何一个都要同步改 `references/` 里的表，否则下一个人会按旧文档返修。

# 量化质检清单（Stage 6）

自动化脚本：`scripts/qa_check.py`。下面标 **[脚本]** 的项由脚本直接算，标 **[人工]** 的需要看 overlay 图或放大原图。

> **所有阈值都是初始值，不是普适真理。** 首次使用请拿 10 页同系列真实页面跑一遍，记录各项实际分布，再回填阈值。校准记录建议写进 `deliverables/_calibration.md`。

---

## 1. 文字零残留

- [ ] **[脚本]** 交付图 OCR 复检：`Surya OCR` + `PaddleOCR` 双引擎，置信度阈值降到 0.25 的敏感模式。
  **判定**：面积 ≥ 页面 0.01% 且置信度 ≥ 0.5 的文本框数量必须为 **0**。其余低置信误检（草叶、木纹被读成字）输出 overlay 交人工确认，不算失败。
- [ ] **[人工]** 艺术字残影：把原文字掩膜区域放大到 200%，看有没有残留的描边、投影、立体字厚度。
- [ ] **[脚本]** 边缘密度核查：修复前后在原 `Text_Mask` 区域算 Sobel/Canny 边缘密度，与周边 30px 环形背景的差值 ≤ 15%。防止残留轮廓线或阴影凹痕。

## 2. 画幅锁定与非篡改

- [ ] **[脚本]** 尺寸零偏差：`(width, height)` 与原图完全相等（ΔW = ΔH = 0），无黑边/白边填充。
- [ ] **[脚本]** 非编辑区 SSIM：在 `1 - Union(Text_Mask, Edit_Mask)` 区域内，交付图与原图 SSIM ≥ **0.9995**。
  依据：原始像素回贴 + 无损 PNG 后该值应为 1.0；留 0.0005 余量是给羽化边与色域转换。低于此值说明发生了非法全局重绘。
- [ ] **[脚本]** 最大像素差：非编辑区内 99.9% 像素的 RGB 最大通道差 ≤ **2**（8-bit），且差值 > **5** 的像素占比为 **0%**。
- [ ] **[脚本]** 保护带零入侵：`Edit_Mask ∩ Protected_Mask` 面积必须为 **0 px²**。

## 3. 风格一致性

- [ ] **[脚本]** 色彩直方图：新增区域（`Edit_Mask` 内）与原图同语义背景区的 HSV 直方图巴氏距离 ≤ **0.25**（> 0.30 视为色温漂移或过饱和）。
- [ ] **[人工]** 线稿宽度与色相：新增元素若带轮廓线，线宽与 `style_dna.line_work` 标称值偏差 ≤ ±20%，线色与原画暗部一致，不出现纯黑 `#000000` 死线。
- [ ] **[脚本]** 纸纹/噪点匹配：新增区域平滑背景的 Laplacian 方差 / 原图同类背景方差 ∈ **[0.75, 1.30]**。防止出现光滑塑料补丁或噪点过重。

## 4. 叙事与跨页一致性

- [ ] **[脚本]** 角色锚点（仅 `multi_page_mode == true`）：新增角色服饰主色 HEX 的 ΔE00 ≤ 5.0，头身比与标志性配饰与 `series_bible.json` 吻合。
- [ ] **[人工]** 补全合理性：每个新增元素都能追溯到 `source_text_span`，且原文没有的元素一个都没多加；无解剖结构错误、无透视悬浮感。
- [ ] **[人工]** 静物不许动：补的路牌/房子/树没有被提示词描述成运动物体。

## 5. 交付规格

- [ ] 无损 PNG，sRGB 8-bit，无文字、无水印、无边框、无对话框。
- [ ] `manifest` 完整：`text_blocks`、`completion_items`、`qa_metrics`、`seedance_output` 四段齐全。
- [ ] 原始输入图未被覆盖，中间产物保留在 `work/`。

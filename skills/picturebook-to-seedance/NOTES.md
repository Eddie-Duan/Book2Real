# NOTES：组装说明、已知问题、待确认项

本 skill 由 Gemini 产出的 `SKILL.md` 初稿组装而成。**运行时不需要读本文件**，它只给人看。

## A. 组装时做的 8 处修正

原稿内部有若干自相矛盾或不可达的条款，直接照抄会导致流程跑不通。做了以下最小改动，均在 `SKILL.md` 中生效：

| # | 原稿问题 | 改成 |
|---|---|---|
| 1 | 铁律 2 说"未被文字遮挡的像素不得改变"，但 Stage 5 要往天空画鸟，必然改这些像素 | 拆成两条：已有元素零改动 + `Edit_Mask` 内背景可替换但须记录 |
| 2 | Stage 3 要求掩膜外 `SSIM == 1.0000`，与后文 `≥ 0.9995` 冲突 | 统一为 `≥ 0.9995`（羽化 + 编码不可能等于 1） |
| 3 | 羽化 3px 未说方向，向外羽化会留半透明文字残影 | 明确"外扩后仅向掩膜内部羽化" |
| 4 | "OCR 返回 0 个框"不可达（草叶、木纹会被误检） | 加门槛：面积 ≥ 0.01% 且置信度 ≥ 0.5 的框为 0 |
| 5 | 宽高比 > 1.8 一律判跨页 | 改为提示确认，不硬阻断 |
| 6 | 阈值（0.25 / 50 / 25px / 10px）无来源 | 统一标注"初始值，需 10 页样本校准" |
| 7 | 写死 Seedance 1.0/1.5/2.0 | 改为按平台当前可选版本核对 |
| 8 | 未要求补全元素溯源，模型可能自行加戏 | 铁律 9：每个新增元素必须对应 `source_text_span` |

另外补了两部分原稿缺失的内容：`references/environment.md` 的**工具链清单 + 无 GPU 降级路径**，以及 `scripts/` 下 3 个可运行脚本（原稿只有质检指标名，没有实现）。

## B. 还没解决的问题（需要你拍板或补料）

1. **"不修改"的最终定义**——本版采用「已有元素不动 + `Edit_Mask` 内背景可换」。如果你的验收标准是字面像素级不变，那补全只能永远 SKIP，这个 skill 就退化成去字工具。**这一条最好先确认。**
2. **画中字处理**——原稿（你确认的约束）是全删。已加"去字后补非可读笔触，不留白板"，但招牌被擦掉本身仍是内容损失，建议先拿一页试试观感。
3. **权重与工作流缺失**——SAM2 / LaMa / Flux.1 Fill / Grounded-SAM / Depth Anything V2 / Surya 的权重与 ComfyUI 工作流没有随附，首次使用需要自备。
4. **阈值未校准**——所有数字都是拍脑袋的初值，必须用你的目标绘本跑 10 页校准。
5. **艺术字掩膜**——渐变字、镂空字、描边字的掩膜仍依赖人工兜底，`scripts/make_text_mask.py` 只覆盖"文字与背景有明显明度差"的常见情况。

# AI Video Prompt Architect 技能说明

## 1. 概述

本技能面向 AI 视频生成任务，用于将初步的视频构想、脚本片段或参考图像，转化为可直接用于视频生成模型的结构化提示词方案。适用范围包括文生视频（Text-to-Video，T2V）与图生视频（Image-to-Video，I2V）两类工作流，支持的模型包括 Sora、Kling、Runway Gen-3、Veo、Luma、Hailuo 与 Seedance。

技能的设计目标是保障多镜头条件下的三项连续性：主体身份的视觉一致性、画面风格与调色的统一性、动作与物理表现的可信性，并在此基础上提供可重复、可校验的出稿流程。

## 2. 主要功能

### 2.1 任务类型识别与参数推断

技能首先判定任务类型（T2V 或 I2V）、目标模型、画面比例、单条时长以及镜头数量。当输入信息不完整时，不进行额外问询，而是依据电影摄影的常规参数设定合理默认值，并在输出开头明确列出所采用的假设，以便使用者校正。

### 2.2 一致性锚点体系

在撰写分镜提示词之前，技能先行生成一份一致性锚点清单（Consistency Bible），对以下三类要素作一次性定义：

| 锚点类别 | 定义内容 |
|---|---|
| 主体锚点 | 年龄、体型、面部特征、眼型、发型与发色、发质、皮肤细节、疤痕或痣、服装层次与面料、鞋履、随身道具 |
| 风格锚点 | 胶片型号或渲染引擎、镜头组、调色方案、对比度、颗粒感、画面比例、质量标签 |
| 环境与光照锚点 | 建筑结构与材质、时间设定、实用光源、主光方向、补光色温、大气效果（雾、尘、雨、体积光） |

锚点文本在后续每一条镜头提示词中逐字复用，不使用代词替代，不作同义改写。该机制是维持多镜头主体一致性的基础。

### 2.3 双形态输出

每个镜头同时输出两种形态，以适配不同模型的输入要求：

- **结构化文本**：按模板 A（T2V）或模板 B（I2V）分字段标注；
- **合并段落**：60 至 120 词的单段描述，适用于不接受方括号标签的模型。

两种形态均按固定顺序组织：风格设定、主体、动作时序、环境与光照、镜头参数（景别、角度、运镜速度、焦距、景深）。

### 2.4 图生视频专项处理

对于已提供参考帧的 I2V 任务，技能将约 80% 的描述篇幅用于运动信息，包括运动矢量、面部微表情、视线转移、眨眼节奏、次级物理表现（发丝、衣摆、粒子、水花）以及相机轨迹。

同时，技能避免重复描述参考帧中已有的静态视觉要素（如颜色、服装款式）。提示词与参考图像相互矛盾是导致画面闪烁与身份漂移的主要成因，因此 I2V 提示词以描述运动方式为主，不重复描述外观。

### 2.5 动作时序与镜头语法约束

- **动作描述**遵循「起始状态—动作过程—结束状态」的时间结构，并明确物理依据，包括重量与惯性、地面接触、风力响应、布料拖拽、水面涟漪方向与扬尘。
- **相机运动**在单个镜头内仅允许一种运动方式，以避免推镜、上摇与环绕叠加所导致的画面几何扭曲。

### 2.6 失败模式与负向约束

技能附带通用负向提示词，并根据场景类型追加对应条款：

| 场景类型 | 追加负向条款 |
|---|---|
| 图生视频（I2V） | `style drift from reference image`, `color shift` |
| 特写镜头 | `warped eyes`, `teeth artifacts` |
| 群像场景 | `cloned faces`, `merged bodies` |

常见失败模式包括以下七类：单镜头内叠加多个情节、提示词与参考图像冲突、动词描述含糊、代词导致主体漂移、相机运动叠加、风格标签相互排斥、忽略模型提示词长度上限致使镜头参数被截断。

对于序列镜头，技能采用首尾帧链接方式：以第 N 个镜头的末帧作为第 N+1 个镜头的 I2V 输入，提示词仅描述增量运动；同时要求遵守 180 度轴线规则并统一调色查找表（LUT）。镜头数量超过约八个时，按场景分段并重新声明锚点清单。

### 2.7 交付前自检清单

输出前逐项核对以下八项：

- [ ] 是否声明全部假设（模型、画面比例、时长、镜头数量）
- [ ] 锚点文本是否逐字一致
- [ ] 每个镜头是否仅含一个主要动作与一种相机运动
- [ ] 是否明确物理依据
- [ ] 是否与参考图像存在矛盾描述
- [ ] 负向提示词是否按场景类型调整
- [ ] 是否同时提供合并段落形态
- [ ] 序列是否标明帧链接关系

## 3. 使用示例

| 使用场景 | 输入示例 | 输出内容 |
|---|---|---|
| 多镜头序列 | 生成一段 15 秒、三个镜头的雨夜追逐场景，Kling 模型，竖屏 | 一致性锚点清单、三组双形态提示词、帧链接说明 |
| 图生视频 | 使参考图像中的人物转头面向镜头 | I2V 模板提示词，以运动描述为主，不重复外观描述 |
| 一致性审查 | 检查该组分镜的人物形象是否前后一致 | 一致性审查意见与自检清单核对结果 |

## 5. 安装与触发

将 `ai-video-prompt-architect` 目录放置于技能根目录下即可被自动发现并热加载，路径为：

```
C:\Users\<用户名>\.dsh\skills\ai-video-prompt-architect\SKILL.md
```

技能目录仅扫描 `<根目录>/<名称>/SKILL.md` 与 `<根目录>/<名称>.md` 两种形式，不递归扫描更深层目录。

安装后，直接以自然语言描述任务即可触发，例如「撰写一段 Sora 视频提示词」「将该镜头拆解为分镜」「使该参考图像中的人物转身」。技能将按第 2 节所述流程生成输出。

## 6. 适用边界

本技能适用于单镜头提示词撰写与多镜头序列规划，不包含视频渲染、素材生成或后期剪辑功能。模型的实际生成效果还受采样参数、种子值与平台版本影响，提示词方案不构成对最终画面的保证。

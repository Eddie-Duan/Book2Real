# 自检门禁四件套与清理合规规程

## 1. 视频结构与编码门禁 (`ffprobe`)

| 检查项 | 指标 | 合格阈值 | 失败动作 |
| :--- | :--- | :--- | :--- |
| 容器与视频流 | `codec_name` & `nb_streams` | 存在有效视频流（`h264`/`hevc`），可完整解码 | `CORRUPT_STREAM`：重下或重生成 |
| 时长偏差 | `abs(actual_duration - target_duration)` | `<= 0.35s` | `DURATION_MISMATCH`：重生成 |
| 分辨率宽高比 | `abs((W_out/H_out) - (W_in/H_in))` | `<= 0.005`（相对误差 `<= 0.5%`） | `ASPECT_RATIO_VIOLATION`：直接拒绝并重生成 |
| 音轨规范 | `audio` 流检测 | 无异常爆音；拼接前统一标准化为 48kHz 立体声静音轨 | 自动由 `concat.py` 注入标准静音轨 |

## 2. 文字与水印零容忍门禁
- **文字检测 (`EasyOCR` / 兜底高频笔画检测)**：
  - 抽取 `0%, 25%, 50%, 75%, 100%` 帧运行 OCR（置信度阈值 `0.35`）。
  - **阈值**：检出有效字符总数必须为 `0`。
  - **失败动作**：视频内出现任何字幕、拟声词或乱码文字均视为生成缺陷，**直接走整段重生成，严禁使用模糊涂抹擦除**。
- **平台水印/角标检测**：
  - 重点扫描四角 `12% x 8%` 区域的高对比边缘突变（与 `clean_keyframe.png` 对应角落差分）。
  - **阈值（并集判据，满足其一即判检出）**：
    1. 角落新增高频边缘密度 `> 0.18`；或
    2. 覆盖型角标：该角变更像素占比 `>= 0.35` 且新增边缘密度 `>= 0.10`（白底贴片+笔画铺满角落时，边缘只占一小圈，纯密度判据会漏检）。
    - 两项阈值均可由 `config.yaml` 的 `watermark_corner_changed_frac_min` / `watermark_corner_changed_edge_min` 覆盖；角落环境动效大的项目可上调以降低误判。
  - **失败动作**：首先核查请求是否携带 `--watermark false`；若确认携带后仍存在角标，进入 `cleanup.py` 评估安全清理可行性。
  - **已知盲区**：细笔画、半透明文字型水印（无贴片底色）在角落的变更面积过小，可能不触发上述判据，需人工目检 `contact_sheet.jpg`。

## 3. 清理层 (`cleanup.py`) 安全与合规红线
1. **执行优先级**：`确认 watermark=false 参数` → `安全区微裁切并等比还原` → `ffmpeg delogo` → `退回重生成`。
2. **保护带硬约束**：任何微裁切操作前，必须加载 `page_manifest.json` 与 `qa_report.json` 计算原图主体的 `25px` 保护区边界；若裁切线入侵保护区 `> 0 px`，立即禁止裁切并退回重生成。
3. **合规红线**：
   - 仅允许清除本流水线调用 Ark API 自有生成内容时产生的平台角标。
   - **严禁去除任何第三方版权水印或法定 AI 生成标识**；最终成片在片尾或元数据中保留合规 AI 生成声明。

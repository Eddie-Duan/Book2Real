## 2. 两条产品线（重要：不要混用）

| | 旧管线（2.5D 程序化） | 新管线（单趟朗读成片，**交付路径**） |
|---|---|---|
| 入口命令 | `plan` / `run` / `ui` | `import-pdf` → `analyze` → `film` |
| 核心模块 | `storyboard.py`→`pipeline.py`→`render.py`→`assemble.py` | `storybook.py`→`storyfilm.py` |
| 服务 | `book2real/webapp.py`（run dashboard） | `book2real/reader_app.py`（阅读器+影院） |
| 时长 | `plan books/cn01` 实测 **77.0s**（<100s，不达标） | `film books/cn01` 实测 **114.79s**（达标） |
| 是否交付 | 否（样张 / I2V 预留） | **是**（Q43 一次生成） |

> 旧管线仍在代码里，README 说"只作回退与测试夹具"。但 `run` 命令目前仍能生成 77s 的不达标成片，若误用会踩 A5「100–200s」红线。

## 3. `book2real/` 包结构（按职责分组）

### 3.1 命令行与配置
| 模块 | 作用 |
|---|---|
| `cli.py` | `python -m book2real <cmd>` 入口，共 **22 个子命令** |
| `__main__.py` | `from .cli import main` |
| `config.py` | 旧管线 `Config`（FilmConfig/QCConfig/RuntimeConfig），读 `configs/*.json` |
| `__init__.py` | `__version__=0.1.0`，把 `vendor/` 注入 sys.path |

**22 个子命令**：`plan run ui reader cloud import-pdf story visuals clip analyze cast models layers castcheck agent sync screens words narrate film evaluate doctor`

### 3.2 入库 / 阅读器包（新管线）
| 模块 | 作用 |
|---|---|
| `ingest.py` | `import-pdf`：PDF → `books/<id>/pages/pXX.jpg` + 文本层 + sha256 |
| `storybook.py` | `analyze`：OCR → 正文选择（中/英）→ 拼音/分词 → 清字 → `reader/book.json` |
| `backend_bridge.py` | 把 `data/books/<id>`（backend 入库结果）桥到 `books/<id>/reader`（文字/OCR/元素卡） |
| `storyfilm.py` | `film`：16:9 单趟逐帧渲染 + 旁白音轨 + `timeline.json`（`W,H=1280,720`、`FPS=24`） |
| `narrate.py` | 逐角色旁白时间轴 |
| `screens.py` / `screens_apply.py` | 长页拆多屏的决策与落盘 |
| `words.py` / `dictwords.py` | 儿童词表 + 词典释义 |
| `syncmedia.py` | `sync`：layers 重建后回挂生成物 |

### 3.3 交互服务（阅读器 + 影院 + 问答/语音）
| 模块 | 作用 |
|---|---|
| `reader_app.py` | 标准库 HTTP 服务：`/`、`/film`、`/api/books`、`/api/film/<id>`（回填 source_w/h）、`/api/film/<id>/video`（Range 206）、`/api/tts`、`/api/ask` |
| `webapp.py` | 旧 `run` 管线的播放器 + dashboard |
| `qa.py` | 规则优先问答（bigram 检索 + 反幻觉，无 key 可跑） |
| `socratic.py` | 追问状态机（纯函数） |
| `voice_state.py` | 打断决策（纯函数，与 JS 1:1 镜像） |
| `tts.py` | edge-tts 旁白 + 缓存（probe / LRU） |
| `web/` | `reader.*`、`film.*`、`qa.js voice.js tts.js offline.js sw.js manifest.json`（无构建） |

### 3.4 人物 Agent 链（`cast/`）
`PageScout → CastClerk → Rigger → MotionDirector → Critic`，另有 `castcheck`（重复肖像）、`agent`（供外部 agent 调用的原子步骤）。

| 模块 | 作用 |
|---|---|
| `cast/pipeline.py` | 整链编排 |
| `cast/pagescout.py` | 页面实体（bbox/面积/主色/签名） |
| `cast/castclerk.py` | 人物墙 + 候选框 |
| `cast/rigger.py` | 刚体切件（手/头 pivot） |
| `cast/motion.py` | 动词/情绪词 → beat JSON |
| `cast/critic.py` | 规则质检（脸/背景残留/关节开洞/正文覆盖） |
| `cast/cutout.py` / `cells.py` / `partkit.py` / `segkit.py` / `inkclass.py` | 抠图/分割原语 |
| `cast/agent_tools.py` / `cast/contracts.py` / `cast/imagekit.py` | 工具与契约 |

### 3.5 视觉 / 2.5D（`vision/`，可选模型）
`sam.py`（SAM 轮廓）、`depth.py`（Depth Anything V2）、`inpaint.py`（SD-1.5 修补）、`faces.py`/`portraits.py`（人脸 QA）、`layers.py`（2.5D 分层）、`checks.py`（Critic 扩展）、`recraft.py`（Recraft 客户端）。

### 3.6 旧管线与云

## 4. `backend/`（融合后端，FastAPI）

```
backend/
  app/
    main.py               FastAPI 入口：REST + WebSocket /ws/voice/{session}
    config.py             环境变量/.env（根 .env 优先，backend/.env 只补缺）
    compat.py             老阅读器字段 → backend 字段归一
    frontend.py           /film、/ 等页面路由（前端挂载）
    api/                  路由分包（当前多集中在 main.py）
    providers/            ASR（local/minimax/http）、TTS（sapi/minimax/local_stream）、LLM
    pipeline/             vad / segmenter / turn / filler / latency
    book/                 ingest / ocr / index / video / store / aliases
    utils.py              PCM 解码 / 重采样 / 语言检测 / json
  scripts/                start_backend.cmd / start_all.cmd / start_local_tts.py|cmd / ingest_materials.cmd
  tools/                  ingest_competition.py / eval_queries.py / ws_latency_probe.py / minimax_*
  tests/                  4 个文件，18 条单测（必须在 backend/ 下跑）
```

**关键路由**：`/api/ask`、`/api/ask/stream`、`/ws/voice/{session}`、`/api/asr`、`/api/tts`、`/api/books`、`/api/books/ingest(-materials)`、`/api/video/{id}/search|describe|frame|elements`、`/api/sessions/{id}/history`、`/api/metrics/latency|turns`、`/health`、`/api/warmup`、`/api/ready`。

**数据目录**：`DATA_DIR` 默认 `Book2Real/data/`，下设 `books/`（页图 NNN.png + queries + book.json）、`cache/`、`source/`、`paperbook.sqlite3`。

## 6. `tests/` 测试架构（双模式，注意）

13 个文件，**12 个是"脚本自跑 + pytest 可收集"双模式**（每个都有 `if __name__ == "__main__"` 自跑入口，跑完打印 `N tests passed`）；只有 `test_layers.py` 是纯 pytest 风格（无 `__main__`）。

| 文件 | 类型 | 用例数（gate 实测） | 依赖服务 |
|---|---|---|---|
| test_cast.py | 双模式 | 10 | 无（纯 CPU） |
| test_evaluate.py | 双模式 | 8 | 无 |
| test_film.py | 双模式 | 9 | **需 `__main__` 里起 server** |
| test_fusion.py | 双模式 | 11 | 无 |
| test_ingest_cloud.py | 双模式 | 5 | 无 |
| test_layers.py | pytest-only | 6 | 无 |
| test_package.py | 双模式 | 7 | 无 |
| test_qa.py | 双模式 | 40（**2 失败**） | 无 |
| test_server.py | 双模式 | 27 | **需 `__main__` 里起 server** |
| test_smoke.py | 双模式 | 15 | 无 |
| test_socratic.py | 双模式 | 24 | 无 |
| test_voice.py | 双模式 | 25 | 无 |
| test_web.py | 双模式 | 15 | 无 |

`gate.py` 的测试门把每个文件当脚本跑（`python tests/test_X.py`），对无 `__main__` 的文件用内置 stdlib 收集器兜底（`gate.py:233-258` 的 `_TEST_HARNESS`）。因此 gate 跑法正确，`pytest tests/` 跑法会把 test_server/test_film 的 server 起不来而误报（详见问题清单 #5）。

`backend/tests/` 另成一套（4 文件 18 条），必须 `cd backend` 后才能 `pytest`。

## 7. 数据产物路径（运行时生成）

```
books/<id>/
  book.json            # 源书元数据 + pages[{file,move,mode,duration}] + film_target + age_range + ai_generated + content_reviewer
  curation.json        # 人工校订层（skip/keep_text/restore/characters/rig_from）
  eval_labels.json     # 评测页码标注（cn01 有）
  pages/pXX.jpg        # 源页图（gitignore）
  text/                # 文本层/OCR（gitignore）
  reader/              # 阅读器包（gitignore）
    book.json          # 逐页 source_page/art/pinyin/segments/scene/spots/characters/ocr_lines/text_boxes
    art/<page>[-k].jpg # 清字插图 + 拆屏裁切
    cast/              # entities.json / clerk.json / rig/ / candidates/ / critic.json / report.json
    characters/        # characters.json + 肖像/切件图
    motion/<page>.json # 每屏 beat
    layers/ words/ narration/ story/   # 可选（layers/words/narrate/story 命令生成）

runs/
  <id>/reader_film/<YYYYmmdd-HHMMSS>/   # film.mp4 + manifest.json + timeline.json + audio/
  cloud/ledger.jsonl                    # 云调用账本
  tts/*.mp3|wav                         # TTS 缓存（key=sha1 前 20 位）

data/                 # 融合后端运行时
  books/<id>/pages/NNN.png + queries/ + book.json
  cache/  source/  paperbook.sqlite3
```

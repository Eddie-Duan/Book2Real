## 0 一句话结论

组委会的分数落在 5 个维度上：绘本生成质量、回答正确性、交互延迟、触控万物识别、多 Agent 协同。
我们现在的状态是：**阅读器/问答/语音/离线/评测门已通（评测门 5/5，161 条测试，问答首响 P50 15ms），
但评分表里最硬的 4 个数字全是空的**——语音问答正确率、触控识别准确率、端到端延迟（含 ASR）、单本生成耗时 P1。
所以 6 个人不是平均分活，而是：**1 人守评测与合规（分数从这出）、2 人补 VLM 与语音两条硬指标、1 人守生成质量与效率、1 人守触控识别、1 人守集成与交付物**。

## 2 六个角色的任务书

### A · 内容理解与生成质量
**现在有什么**：OCR（rapidocr）+ 清字（Telea）+ 拼音/分词 + 人物链（PageScout→CastClerk→Rigger→MotionDirector→Critic），阅读器已能点字/点画。
**缺什么**：VLM 通道**一行没有**（全仓 grep `VLM` = 0 命中）；故事改编/分镜没接 LLM；角色一致性**没有度量**。
**要做**：
1. 接 VLM（`vision/vlm.py`，OpenAI 兼容多模态，key 走 `B2R_VLM_*`），先做「整页→实体清单+适合儿童的描述」，输出 schema 固定。
2. 角色一致性度量：用 DINO/CLIP 嵌入（或先颜色直方图占位）算跨页同一角色相似度，产出 `cast/consistency.json`。
3. 分镜 JSON（StoryBible → 每页 beat）接 LLM，带 schema 校验 + 失败回落模板。
**验收**：`python scripts/eval_metrics.py` 里多出「角色一致率」「图文匹配抽检」两行真数字；说明书 7.2 的「风格一致性/页间连贯性/图文准确度」三格能填。
**别碰**：`web/`、`reader_app.py`、`scripts/gate.py`（改坏了别人全红）。

### B · 视频生成与效率
**现在有什么**：16:9 成片、2.5D 分层视差、旁白 TTS、`pregen` 后端（真 I2V 靠预生成喂片）。
**缺什么**：真 I2V **没接**；单本耗时 **从没按 P1 统计过**（HANDOFF 只有零散「23 页 120 s」）。
**要做**：
1. 加计时埋点：整本从 analyze 到 finish 的墙钟时间，写 `runs/<id>/timing.json`，`--jobs` 可调。
2. 做 480p 草稿档 + 关键镜头 I2V 的可选开关（默认关，演示开）。
3. 把「单本耗时」变成可复跑数字：3 本书 × 各跑 2 次，取中位。
**验收**：`docs/METRICS.md` 多出「单本生成 P1 耗时」行（n=6）；说明书 7.2「生成效率」格可填。
**别碰**：`qa.py`、`web/`。

### C · 语音问答链路
**现在有什么**：`/api/ask` 规则模式（P50 15ms、引用 100% 可回溯、书外拒答）、苏格拉底追问、打断状态机（Python 有测、JS 镜像）、句级 TTS 缓存（命中 63.9ms）。
**缺什么**：**真 ASR 没有**（只有浏览器 Web Speech，Android WebView 不支持）；端到端延迟**没测含 ASR 的**；问答正确率没有评测集。
**要做**：
1. 接服务端 ASR（FunASR/SenseVoice 小模型，或先 Whisper-tiny）到 `/api/asr`，浏览器 ASR 保留为首选、服务端为兜底。
2. 端到端链路计时：ASR 结束 → 检索 → 回答 → TTS 首帧，埋点写 `runs/eval/latency.json`。
3. 真麦克风打断彩排（回声保护 600ms 够不够），把结论写进 HANDOFF。
**验收**：`docs/METRICS.md` 出「端到端延迟 P95」；说明书 7.2「语音问答正确率 / 端到端延迟 / 实时稳定性」三格能填。
**别碰**：`vision/`、`storyfilm.py`。

### D · 触控万物识别
**现在有什么**：点击链路（点字→词典/拼音、点热点→预存实体文案、点空白→本页 scene）+ 昨天的问答面板。
**缺什么**：**"识别"那一半是假的**——现在只查预存实体表，不认图里没标注的东西；Top-1 准确率没有数。
**要做**：
1. `vision/vlm.py` 的 `describe_region(book, page, box)`：按 bbox 裁剪页图 → VLM 识别 → 结构化 `{name, kind, desc, confidence}`；无 key 时返回 `None` 走现有降级。
2. 点击命中优先级：索引实体 > VLM 局部识别 > 本页 scene；三者都在 `qa.py` 里收敛（和 C 对齐接口，别各写一套）。
3. 造 100 个点击测试样本（坐标 + 期望实体），算 Top-1。
**验收**：`docs/METRICS.md` 出「触控识别 Top-1 准确率（n=100）」；说明书 7.2「触控万物识别」格可填。
**别碰**：`qa.py` 的检索/引用逻辑（那是 C 的地盘），只在约定函数上接。

### E · 评测与合规（建议队长兼）
**现在有什么**：`scripts/gate.py` 五门（5/5 过）、`eval_metrics.py` 出 5 项实测、`METRICS.md` 实测/目标分列。
**缺什么**：**评估集适配层没有**（组委会给的 6 本书 + Query 音频集要能批量跑并导出结果）；**内容审核层没有**（grep 审核 = 1 命中）；**AI 生成标识没有**；说明书第 4 章来源清单全空；合规自检 7 项全空。
**要做**：
1. `scripts/eval_set.py`：吃组委会样本目录 + Query 音频集，批量跑，输出固定格式结果文件（题目→系统回答→是否正确→耗时）。
2. 审核与标识：输入/输出各一道（敏感词表 + LLM 复核可选），每份生成物带 `source: ai|rule` 与「AI 生成」角标，页面可见。
3. 填说明书第 4（来源清单）/7（测试结果）/9（合规自检），指定「内容安全复核责任人」。
**验收**：合规自检 **7/7 是**；说明书每个空格要么有数要么写「未测（原因）」；`eval_set.py` 能对 1 本样本端到端跑通并出结果文件。
**别碰**：业务代码。E 只写 `scripts/`、`docs/`、以及审核模块；要改业务逻辑找对应负责人。

### F · 集成与交付物
**现在有什么**：零构建前端、离线 SW（303 文件/36.5MB，杀服务端仍可翻）、CSP/路径守卫、`--host`、一键 `python -m book2real reader`。
**缺什么**：说明书未填（模板在 `docs/纸书智伴项目书.docx`）；**现场 SOP 与录屏兜底没有**；平板/触屏没真机验过。
**要做**：
1. 说明书成稿 ≤20 页（与 E 分工：F 写 1/2/3/5/6 章与附录 A/B，E 写 4/7/9 章）。
2. 附录 A 演示步骤 + **故障备用**：录屏、关键截图、断网降级路径。
3. 平板/触屏适配与实测（44px 热区、软键盘、iOS/Android 各一次）；局域网 `--host 0.0.0.0` 的演示流程（注意 http 下 SW 不可用，要如实提示）。
**验收**：一条命令起服务；断网仍能演示核心链路；说明书 PDF 出得来回读一遍没有「____」。
**别碰**：算法侧。

## 4 协作规则（6 个人同时改代码还不打架）

1. **写域互斥**：上表"主要写域"就是你的地。要动别人的文件，先在群里说一句，由对方改或对方点头。
2. **接口先定**：跨角色的接口（`/api/ask`、`/api/asr`、`describe_region`、评测结果格式）先写进 `docs/INTEGRATION_CONTRACT.md`，再各自实现。
3. **合并门槛 = gate**：任何人提交前跑 `python scripts/gate.py`，必须 **5 通过 0 失败** 才算完成；测试只许加不许放宽（这是纪律，昨天已经因为一个 0.01 的阈值抓出真 bug）。
4. **数字才算完成**：说"做完了"必须带实测数字（n、环境、中位/P95）。禁止"应该能跑"。
5. **每日 15 分钟站会**：昨天做了什么/今天要交什么/被谁挡住。被挡超过半天，直接找对方，不要等。
6. **每周一次全员联调**：用同一本书从头跑到尾，任何人跑不通就算当周不算完成。

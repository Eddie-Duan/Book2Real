## 2. 非交互视频（评“绘本生成质量”）

| 指标 | 官方口径 | 安全解释 |
|---|---|---|
| 时长 | Q26：100–200 s；Q39：绘本视频 ≤3 min | 取交集 100–180 s 最稳 |
| 分辨率 | ≥720P（1280×720），推荐 1080P | 1280×720 是底线 |
| 帧率 | ≥24 fps | 24 fps 刚好达标 |
| 音轨 | 必须有人声/音频 | 无音轨直接不合格 |
| 内容覆盖 | 正文每页都要有体现；不强制一页一镜；跨 2–3 页可合并；封面可作片头；版权页不强制（Q33） | 不能掉页、不能只拍几页 |
| 生成次数 | 同一册必须一次生成，不能二次编辑（Q43） | 最高风险条款 |
| 效率 | 整本视频总耗时是主要评价指标（Q26） | 达标前提下越快越好 |

## 3. 交互演示视频（评“语音+图像交互”）

| 指标 | 官方口径 |
|---|---|
| 形式 | 交操作录屏即可，不需要另给可交互入口（Q39） |
| 时长 | ≤5 分钟，与绘本视频分别计时（Q39） |
| 拍摄 | 屏幕录制浏览器 + 系统声音；不需要真人出镜；一镜到底、不剪辑 |

| 内容 | 点选→暂停→介绍；语音问答；视频内检索；跨语言问答；触控过程要看得见 |

## 4. 交互功能标准

### 4.1 语音问答

- 首响 2 秒：口径 = 用户话音结束 → 听到 TTS 首音（Q9、Q34）。
- 统计达标比例，不是只看一次；warmup 预加载后再统计，首轮冷启动不计（Q34）。
- 回答正确率按 Query 条数计（Q11）；官方每本 50 条 Query 音频（16k/16bit wav，儿童风格 TTS，安静场景，Q15）。

### 4.2 视频内检索四能力（Q11）

1. 跳到指定帧；
2. 框选指定人物/动物/物品；
3. 描述指定帧内容；
4. 查找视频中的指定字/词（非字幕）并框出来。

### 4.3 触控

- 粒度：独立语义对象级（人物/动物/物品），不是整页（Q28）。
- 流程：点击目标 → 视频立即暂停 → 展示该目标介绍（Q35）。
- 同一目标所有可见且可识别的帧都要能点；完全出画不要求（Q35）。
- 官方说不以评委暂停点击为主要验收方式，但点选流程本身必须正确（Q35）。
- PDF 自带可点击元素标注，可直接作为热区来源（Q13、Q14）。

### 4.4 语言

- 测中文和英文；新绘本语种现场决定；会测跨语言问答（Q41）。

## 6. 评分与红线

评分维度（PDF 第 5 页 §6）：

1. 绘本生成质量：风格一致性、页间连贯性、图文准确度、生成效率；
2. 回答正确性：语音问答 + 视频内容检索；
3. 交互延迟：端到端、实时性、稳定性；
4. 触控式万物识别：识别准确率；
5. 系统实现与多 Agent 协同；
6. 规范合规：材料完整、工具/数据披露、儿童内容审核责任人与年龄适配。

扣分红线（任一即取消成绩）：

- 关键生成/复现说明无法定位；
- 工具或数据来源披露不完整；
- 使用未授权绘本；
- 把赛前预先固定的结果冒充现场实时生成。

## 7. 口径冲突与安全解释

| 冲突/模糊 | 官方两条口径 | 建议 |
|---|---|---|
| 非交互时长 | 100–200 s（Q26） vs ≤3 min（Q39） | 按 100–180 s 排产，两边都不碰线 |
| “一次生成”边界 | Q43 说同一册不能二次编辑；未明确同一次任务内多段拼接算不算 | 不要把“分段生成+拼接”写成官方允许；说明书如实写“同一任务链内分段、无损接带”，并准备被问 |
| 封面/片头 | Q33 封面可作片头 | 片头可以做，但后期加封面/换音轨有 Q43 风险；严格合规应把封面放进生成首段 |
| 2 s 首响 | PDF 只写“基础门槛，具体数值定稿为准”；2 s 来自 Q9/Q34 | 引用时写“Q9/Q34 口径”，不要说 PDF 原文 |
| 触控“所有可见帧” | Q35 要求所有可见可识别帧可点，又说不以暂停点击为主要验收 | 自测按“抽帧点中心 ±5% 命中”做，别只测一个时间点 |

## 3. 分类要点

### 3.1 交付物与提交规范（Q20）

企业预选赛材料（**11.25 18:00 截止**），四份文件：

1. `项目说明书.pdf` —— **20 页不是硬限制**
2. `项目源代码.zip`
3. `绘本名称+非交互视频.mp4`
4. `绘本名称+交互演示视频.mp4`

整体打成一个文件夹压缩，命名 `学校-院系-姓名.zip`。

### 3.2 输入与链路

- **唯一输入是绘本 PDF**：不需要支持"只给文字就生成视频"；拍照/页图上传不是主路径（Q22、Q3）。
- **OCR 不限定实现**：可用独立 OCR，也可直接由 VLM 完成识字+结构化；只要输出逐页文字、页码、必要图文结构且**可与原书核对**即算达标，**不强制独立 OCR 模块**（Q40）。
- **PDF 自带可点击元素标注**（Q13、Q14）——可直接作为触控热区来源，不必自己从头检测主体。
- **多 Agent 编排不指定框架**（Q25）。
- **允许微调/自训**：可自行选数据增强与微调；但微调后的模型必须**部署在自带电脑上并提供权重**（Q23、Q24）。
- **闭源 API 允许、无限制**（Q17）；**不需要云 GPU**，调外部接口、自己设备演示即可（Q18）。

### 3.3 视频生成

- 覆盖要求：**完整覆盖正文主要情节**，**正文每页都必须在成片中有体现**，但**不强制一页一镜**；跨 2–3 页的连续情节允许合并成连贯片段（Q33）。
- 封面可作片头；版权页不作强制要求；无字过渡页灵活处理，但**有情节推进作用的画面要保留**（Q33）。
- **一次生成、不许剪**（Q43）——这条直接否定"多镜头分别生成再 ffmpeg 拼接"的常规做法，需在方案层面重新设计。
- 可复现性：**不要求相同输入逐帧一致**，重点看新任务下的质量、效率、稳定性、泛化（Q37）。
- 风格一致性/页间连贯：**量化指标 + 人工盲评**（Q27）。

### 3.4 交互与检索

- **视频内检索是新增的大项**（Q11），明确要支持：
  - 跳到视频指定帧
  - 框选指定人物/动物等元素
  - 描述指定视频帧的内容
  - 查找视频中的指定字/单词**（非字幕）并框出来**
- 触控对象粒度到独立语义对象级，且**移动中所有可见帧可点**（Q28、Q35）。
- 多模态对话历史需**覆盖当前绘本的完整交互过程**，支持跨轮上下文与连续对话；不强制跨会话长期保存（Q29，末段被名牌遮挡）。
- 跨语言问答会测（Q41）。

### 3.5 现场

- 携带自己的设备演示，网页或平板均可（Q19）。
- 现场给一本**全新绘本 PDF**，**实时生成**、**现场提问**，不给准备时间（Q21、Q32）。
- 用**好未来 wifi**；服务端与演示端建议同机（Q38）。
- 现场中英文绘本由**主办方决定**，可能是英文（Q41）。

### 3.6 模型与 API

- 企业预选赛阶段**不限定 API**，可自行选用（Q16）。
- 企业主体赛阶段官方提供：**DeepSeek-V4.1 Flash、豆包文生图基础版、Seedance 文生视频基础版**（Q16，原片作"企业主题赛"疑为笔误）。
- 领取方式：**邮件发账号**；**2026.11.30** 开通；**总额度 ≤500 元、并发 ≤20**（Q42，日期已按官方口径更正）。
- 官方素材可否外发：**可以访问商用 API**；提供给队伍的是 PDF，签名链接/图片链接可自行生成（Q36）。

### 3.7 合规

- 儿童内容安全：国家**没有**公开可下载的儿童违禁词黑名单；须遵守《未成年人保护法》《未成年人网络保护条例》《可能影响未成年人身心健康的网络信息分类办法》，分龄参考网信办《移动互联网未成年人模式建设指南》（Q30）。
- 知识产权承诺书、数据使用承诺**没有单独模板，写进项目说明书**（Q31）。

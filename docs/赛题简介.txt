围绕 “让传统纸质图书焕发新生” 这一阅读场景，
本赛题要求参赛队伍构建 OCR、VLM、文生故事、文生视频等多个专业 Agent 的协同链路，
从纸质图画书与文字描述出发，
自动生成完整的多模态互动绘本视频，
并搭建智能语音交互、视觉触控式万物识别等互动能力，
让读者在阅读过程中随时提问、随时探索，
AI 伴读助手实时响应。
参赛队伍需基于组委会提供的纸质绘本样本与 Query 测试音频集，
构建可拍照、可生成、可交互的伴读系统；
总决赛现场限时完成新绘本的互动化改造与实时问答。
作品以网页 / 平板 Demo + 评估集实测数据交付，
考察文生视频、ASR/TTS、VLM、OCR 及多 Agent 协同工程能力。

# 绘本入库与 OCR

## 1. 一键入库

```bash
python tools/ingest_competition.py --zip "<素材zip路径>/纸书智伴企业预选赛绘本素材.zip"
```

输出在 `data/books/{book_id}/`：

```
book.json         结构化结果
pages/001.png     页图（150 DPI）
queries/06.wav    Query 音频（按脚本编号）
video/            视频索引（后续建）
```

`book_id` 规则：`中文绘本01 → cn01`，`英文绘本03 → en03`。

## 2. 两类 PDF

| 类型 | 例子 | 策略 |
| --- | --- | --- |
| 原生文字层 | 中文 3 本（内页 1304×652 对开） | `PyMuPDF get_text("dict")` 直接取行/字号/bbox，不跑 OCR |
| 扫描页 | 英文 3 本（约 28 页/本） | 文字层只有赛事水印 → 渲染 150 DPI PNG → RapidOCR |
| 封面/无字页 | 中文封面、英文插图页 | 正文为空时 OCR 封面；纯插图页允许 `story_text=""` |

判断规则：正文（去水印后）少于 2 个字符才 OCR；避免中文短页（如“九块……”）被 OCR 水印污染。

## 3. 清洗规则

### 3.1 水印

赛事 PDF 带“仅供第二届北京市大学生…请勿外传”“纸书智伴…赛题参赛使用”等水印（有的在文字层，有的在扫描图里）。`WATERMARK_RE` 过滤：

```
仅供 | 外传 | 纸书智伴 | 纸书智 | 北京市 | 大学生 | 人工智能 |
创新大赛 | 第二届 | 赛题 | 参赛使用 | 学而思阅读树 | 学而思大阅读 | 学而思内容中心
```

OCR 会把水印切成碎片，所以关键词按片段匹配，而不是整句。

### 3.2 教学栏

中文对开页底部有“汉字源流 / 阅读指导 / 甲骨文 / 楷书…”栏，字号 6–12。规则：

- 含 `阅读指导|汉字源流|甲骨文|楷书|金文|小篆|隶书|读一读|说一说|想一想|猜一猜` → `teaching`
- y > 页高 90% → `teaching`
- 其余 → `story`

`teaching_text` 会进入检索索引（低权重），但**不参与脚本页面定位**，因为它经常复述问题，会把场景页带偏。

### 3.3 阅读顺序

- 中文对开页（宽 > 900px）按左半/右半分别排序，先左后右；
- 中文按 y 再 x，英文按 y 再 x；
- 英文行间加空格，中文行间不加。

## 4. 脚本文本

`parse_script()` 解析 `中文绘本01.txt`：

| 脚本形态 | 识别为 |
| --- | --- |
| `01. 播放 （必选）` | `playback`，`required=true` |
| `04. 找到搭了九块积木的画面` | `find_scene`，`scene_query="搭了九块积木"` |
| `18. 查找“我又不是故意的”` | `find_text`，`text_query` |
| `[点击] 点击积木城堡 \| 暂停并展示城堡信息` | 挂到上一条，`click.target/action` |
| `05. 他们在搭什么？` | `question` |

编号与音频文件一一对应（`06.wav` ↔ 第 6 条）。

## 5. 页面定位（单调 DP）

脚本 50 条动作按故事顺序推进，但很多是“问画面/问原因/高亮”，没有强关键词。做法：

1. 每条动作取 `scene_query / text_query / click.target / text` 四个字段，对每页算匹配分：
   - 正文（story）全权重；
   - 教学栏不参与定位；
   - 归一化后整串命中给 10–15 分，否则按字符 bigram 命中比例给分；
   - 首句命中额外 +0.5（新场景通常在第一句）；
   - 语义纠偏：“搭积木”不能匹配到“倒塌”页，“倒塌”不能匹配到“没有倒”页。
2. 单调 DP：`dp[i][p] = score(i,p) + max_{q<=p} dp[i-1][q] - 跳页惩罚`；
   - 场景动作前进 1 页 +0.25，跨多页 +0.10；
   - 同页 +0.15；跳页 0.08/页；
   - 首条固定第 1 页、末条固定最后一页。
3. 回溯得到每条动作页码，写入 `script.items[].page`，并用于元素卡页码。

效果（中文绘本01）：`1-3→p1, 4-8→p3, 9-11→p4, 12-15→p5, 16-19→p6, 20-26→p7, 27→p8, 30→p9, 34→p10, 38-44→p11, 45-50→p12`。

**局限**：英文扫描页的插图没有文字，纯靠文本/页序，个别场景可能偏 1–2 页。视频组用 manifest 精确覆盖即可。

## 6. 元素卡

点击目标来自脚本 `[点击]` 行：

- `name` = 点击对象（如“积木城堡”“熊猫右眼”）；
- `page` = 所属脚本动作的 DP 页码；
- `bbox` = 在页 `blocks` 里找包含目标文字的块；找不到则为 `null`（纯插图对象）；
- `info` = 含该目标的第一句正文；找不到则用该页第一句；再兜底通用描述；
- `action/required` 原样保留，供前端展示。

英文书的点击目标（中文）用 `aliases.py` 映射到英文单词（castle/robot/popcorn/…）参与定位；bbox 仍可能为空，建议 manifest 提供。

## 7. 视频索引

```bash
curl -X POST http://127.0.0.1:8790/api/video/cn01/index-path \
  -H "Content-Type: application/json" \
  -d '{"video_path":"E:/videos/cn01.mp4","manifest_path":"E:/videos/cn01_manifest.json"}'
```

- 默认 1 fps 采样（`VIDEO_SAMPLE_FPS`），最多 900 帧；
- 每帧 RapidOCR，过滤水印，存归一化 bbox；
- `search_text` 返回 `t / frame / text / bbox`，供“查找文字并框出”；
- 无 manifest 时按页数均分时长生成场景；
- `describe` 目前返回页文本/元素卡，后续可接 VLM。

## 8. 已知问题与改进

1. 英文扫描页 OCR 可能把插图上的艺术字/标题识别成正文；目前全部保留（对“查找文字”有用），但可能影响问答检索。
2. 中文封面 OCR 会残留出版社/丛书名；不影响内页问答。
3. 点击对象的 bbox 仅对“文字可见”的目标有效；插画对象需 manifest 或视觉检测。
4. 如果后续能离线装 CLIP，可用页图/文本相似度补足英文场景定位；当前 HF 网络不可达，未启用。

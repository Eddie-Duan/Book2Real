# 交互视频录制全流程（cn01 + en01）

> 2026-11-25，代码基线 feat/skills-tuning。给“用自己电脑录官方交互视频”的人看。
> **录制只使用 /film?book=cn01 和 /film?book=en01；不使用 /?book=... 页面。**
> 先给结论：**两个 final_movie.mp4 只是“非交互成片”，光有它们录不了交互视频。**
> 还需要同一条片子的 timeline.json + 点击目标表 + 阅读器服务；这两样我打成了两个交接包。

## 0.0.1 只用生成视频，不碰电子书

- `/film?book=<id>` 页面只加载一个 `<video>`：`/api/film/<id>/video`；没有 `<img>`、没有 `<iframe>`、没有绘本页图。
- cn01 的 2s 封面是**成片第一帧**；en01 无封面；都不是电子书页。
- **不要点左上角“← 绘本”**，那会跳回阅读页；录屏全程留在 `/film`。
- 页面上的标题、按钮、右侧介绍卡、问答文字是**交互 UI**，不是电子书页面；画面像素只来自生成的 mp4。

## 3. 录屏还是别人拍？

**录屏，不用真人出镜，也不用别人拍。**

官方 Q39 原话：“带交互版交操作录屏即可，不需另给可交互入口。”

推荐：
- Windows 自带：Win + G → 捕获浏览器窗口 + 系统声音 + 麦克风。
- 或 OBS：显示器/窗口捕获 + 桌面音频 + 麦克风；1080p / 30fps；输出 mp4。
- 不要用手机拍屏幕；不要露脸；不要后期剪辑。

> 现在只用影片页：**“🎤 语音提问”会自动判断**——听到问题就调 /api/ask 回答并 TTS；听到“找到/查找/高亮”就做画面检索。只使用 /film?book=... 这一个页面。

录屏里必须能看见：
- 鼠标/触控点在哪里；

## 7. 常见问题

| 现象 | 原因/处理 |
|---|---|
| /film 404 或回到旧片 | 没设 B2R_FILM_SEEDANCE=1；或端口连到了 ui 不是 reader |
| 页面能开但没画面 | 交接包没解压到 runs/<id>/seedance_film/<stamp>/，或 film.mp4 不在 |
| 点元素没反应 | 当前时间不在该 shot；用第 2 节的时间点；或框是 shot 级，角色已走动 |
| 查字框很小 | 用了旧 timeline；用 feat/skills-tuning + 交接包里的 timeline |
| 语音没反应 | .env 没配 MINIMAX_API_KEY；浏览器没给麦克风权限；系统声音没录进 OBS |
| 录屏没声音 | OBS 只加了麦克风，没加“桌面音频”；或 Win+G 没开系统声音 |

## 8. 诚实预期：能达标吗？

能达标：
- 四能力（跳帧/点选/描述/查字）都有可演示路径；
- 点击→暂停→介绍流程完整；
- 语音首响 2 秒有实测基础（MiniMax ASR+TTS，P95≈1.07s）；
- 中英双语 + 跨语言问答有 en01 可演示。

仍有风险：
- 点击框是 shot 级，不是逐帧；同一 shot 内角色走动时可能点偏。官方“所有可见帧都能点”严格验收会扣分。
- p01 封面只是 0–0.001s 元数据段，画面里没有封面原图。
- en01 是 480p，且点击框是页级 fallback，精度比 cn01 弱。
- 语音音色是否“幼儿园老师”只能人听，ASR 不验音色。

结论：**录一版能演示、能讲清四能力；但“所有可见帧点击精度”这一项还不是满分。** 如果时间够，先补逐帧框再录；不够就先录这一版。

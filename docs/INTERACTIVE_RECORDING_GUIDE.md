# 交互视频录制全流程（cn01 + en01）

> 2026-11-25，代码基线 983f82b。给“用自己电脑录官方交互视频”的人看。
> 先给结论：**两个 final_movie.mp4 只是“非交互成片”，光有它们录不了交互视频。**
> 还需要同一条片子的 timeline.json + 点击目标表 + 阅读器服务；这两样我打成了两个交接包。

## 0. 你现在有什么、还缺什么

你手上（群里）：
- cn01 final_movie.mp4（145.26 MB，150.08s，1280×720）
- en01 final_movie.mp4（92.09 MB，180.08s，854×480）

要录交互视频还缺：
- 两个交接包（成片 + timeline + click_targets + 官方 wav）：
  - dist/interactive_handoff_cn01.zip（161 MB）
  - dist/interactive_handoff_en01.zip（102 MB）
- 仓库代码（983f82b）
- 语音问答要 .env 里的 MINIMAX_API_KEY（只录点击/检索可以先不配）

## 1. 一次性准备

### 1.1 拉代码

    git clone git@github.com:Eddie-Duan/Book2Real.git
    cd Book2Real
    git checkout 983f82b

### 1.2 放交接包

把两个 zip 解压到仓库根，解压后应该是：

    runs/cn01/seedance_film/<stamp>/film.mp4
    runs/cn01/seedance_film/<stamp>/timeline.json
    runs/en01/seedance_film/<stamp>/film.mp4
    runs/en01/seedance_film/<stamp>/timeline.json
    books/cn01/click_targets.json
    books/en01/click_targets.json

zip 里已经按这个路径打好了，直接“解压到当前文件夹”即可。

### 1.3 配 .env（语音问答才需要）

    cp .env.example .env
    python scripts/setup_env.py

至少填 MINIMAX_API_KEY；不配也能录点击/检索/描述，但录不了语音问答。

### 1.4 起阅读器服务

    $env:B2R_FILM_SEEDANCE="1"
    python -m book2real reader --books books --port 8796

浏览器打开：

    http://127.0.0.1:8796/film?book=cn01
    http://127.0.0.1:8796/film?book=en01

**必须带 B2R_FILM_SEEDANCE=1**；不带会读旧 2.5D 片。

## 2. 录之前先自测（2 分钟）

在 cn01 页面按顺序点一遍，确认：

1. 进度条拖到 0:10，点画面中央偏右 → 应暂停并出现“积木城堡”。
2. 拖到 1:46（p09 s2），点右侧卡片区域 → 应出现“生日卡片”。
3. 拖到 1:56（p09 s3），点狗 → 应出现“黄米团”。
4. 查字框输入“我又不是故意的” → 应跳到 1:00 左右并画框。
5. 找画面框输入“找到搭了九块积木的画面” → 应跳到 p12 并画框。
6. 点“描述这一帧” → 右侧应引用当前页正文。
7. 如果配了语音：点“语音提问”，播放一条 query_wavs/06.wav，允许浏览器麦克风 → 2 秒内应开始回答。

en01 页面自测：
1. 点“机器人/爆米花/游戏机” → 暂停 + 介绍。
2. 输入“popcorn”或“爆米花” → 跳到对应页。
3. 语音问一句英文/中文 → 应回答。

任何一项不通过，先别录，按第 6 节排查。

## 3. 录屏还是别人拍？

**录屏，不用真人出镜，也不用别人拍。**

官方 Q39 原话：“带交互版交操作录屏即可，不需另给可交互入口。”

推荐：
- Windows 自带：Win + G → 捕获浏览器窗口 + 系统声音 + 麦克风。
- 或 OBS：显示器/窗口捕获 + 桌面音频 + 麦克风；1080p / 30fps；输出 mp4。
- 不要用手机拍屏幕；不要露脸；不要后期剪辑。

录屏里必须能看见：
- 鼠标/触控点在哪里；
- 视频暂停、右侧介绍卡；
- 搜索/查字后画面跳转和框；
- 语音问完后 2 秒内开始回答（系统声音要录进去）。

## 4. cn01 交互视频脚本（约 90–120 秒）

1. 打开 /film?book=cn01，点播放，播 3–5 秒。
2. 拖到 0:10，点“积木城堡” → 暂停 + 介绍；停 2 秒。
3. 拖到 1:46，点“生日卡片” → 暂停 + 介绍；停 2 秒。
4. 拖到 1:56，点“黄米团” → 暂停 + 介绍；停 2 秒。
5. 查字输入“我又不是故意的” → 跳到 1:00 并框出；停 2 秒。
6. 找画面输入“找到搭了九块积木的画面” → 跳到片尾并框出；停 2 秒。
7. 点“描述这一帧” → 读一下右侧正文；停 2 秒。
8. 点“语音提问”，播放官方 query_wavs/06.wav（“这张卡片送给谁？”）→ 等回答开始；停 2 秒。
9. 结束录制。

## 5. en01 交互视频脚本（约 60–90 秒）

1. 打开 /film?book=en01，播 3–5 秒。
2. 点“机器人”或“爆米花” → 暂停 + 介绍。
3. 输入“popcorn” → 跳到对应页并框出。
4. 点“描述这一帧”。
5. 语音问一句（中文或英文），等 2 秒内回答。
6. 结束。

## 6. 录完检查

- 时长 ≤ 5 分钟；有声；一镜到底；没有剪辑。
- 文件名：
  - 一起搭积木吧+交互演示视频.mp4
  - Going to the Cinema+交互演示视频.mp4
- 和两个 final_movie.mp4 一起交；两段视频分别计时。

## 7. 常见问题

| 现象 | 原因/处理 |
|---|---|
| /film 404 或回到旧片 | 没设 B2R_FILM_SEEDANCE=1；或端口连到了 ui 不是 reader |
| 页面能开但没画面 | 交接包没解压到 runs/<id>/seedance_film/<stamp>/，或 film.mp4 不在 |
| 点元素没反应 | 当前时间不在该 shot；用第 2 节的时间点；或框是 shot 级，角色已走动 |
| 查字框很小 | 用了旧 timeline；用 983f82b + 交接包里的 timeline |
| 语音没反应 | .env 没配 MINIMAX_API_KEY；浏览器没给麦克风权限；系统声音没录进 OBS |
| 录屏没声音 | OBS 只加了麦克风，没加“桌面音频”；或 Win+G 没开系统声音 |

## 8. 诚实预期：能达标吗？

能达标：
- 四能力（跳帧/点选/描述/查字）都有可演示路径；
- 点击→暂停→介绍流程完整；
- 语音首响 2 秒有实测基础（MiniMax ASR+TTS，P95≈1.07s）；
- 中英双语 + 跨语言问答有 en01 可演示。

仍有风险：
- 点击框是 shot 级，不是逐帧；同一 shot 内角色走动时可能点偏。官方“所有可见帧都能点”严格验收会扣分。
- p01 封面只是 0–0.001s 元数据段，画面里没有封面原图。
- en01 是 480p，且点击框是页级 fallback，精度比 cn01 弱。
- 语音音色是否“幼儿园老师”只能人听，ASR 不验音色。

结论：**录一版能演示、能讲清四能力；但“所有可见帧点击精度”这一项还不是满分。** 如果时间够，先补逐帧框再录；不够就先录这一版。

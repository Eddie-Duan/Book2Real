## 3. 录屏还是别人拍？

**录屏，不用真人出镜，也不用别人拍。**

官方 Q39 原话：“带交互版交操作录屏即可，不需另给可交互入口。”

推荐：
- Windows 自带：Win + G → 捕获浏览器窗口 + 系统声音 + 麦克风。
- 或 OBS：显示器/窗口捕获 + 桌面音频 + 麦克风；1080p / 30fps；输出 mp4。
- 不要用手机拍屏幕；不要露脸；不要后期剪辑。

> 注意：**影片页的“🎤 语音提问”是“找画面”，不是问答**；真正的语音问答在阅读页（/?book=...）的“问一句 / 🎤 说”。录视频时两页都要出现。

录屏里必须能看见：
- 鼠标/触控点在哪里；
- 视频暂停、右侧介绍卡；
- 搜索/查字后画面跳转和框；
- 语音问完后 2 秒内开始回答（系统声音要录进去）。

## 7. 常见问题

| 现象 | 原因/处理 |
|---|---|
| /film 404 或回到旧片 | 没设 B2R_FILM_SEEDANCE=1；或端口连到了 ui 不是 reader |
| 页面能开但没画面 | 交接包没解压到 runs/<id>/seedance_film/<stamp>/，或 film.mp4 不在 |
| 点元素没反应 | 当前时间不在该 shot；用第 2 节的时间点；或框是 shot 级，角色已走动 |
| 查字框很小 | 用了旧 timeline；用 feat/skills-tuning + 交接包里的 timeline |
| 语音没反应 | .env 没配 MINIMAX_API_KEY；浏览器没给麦克风权限；系统声音没录进 OBS |
| 录屏没声音 | OBS 只加了麦克风，没加“桌面音频”；或 Win+G 没开系统声音 |

## 8. 诚实预期：能达标吗？

能达标：
- 四能力（跳帧/点选/描述/查字）都有可演示路径；
- 点击→暂停→介绍流程完整；
- 语音首响 2 秒有实测基础（MiniMax ASR+TTS，P95≈1.07s）；
- 中英双语 + 跨语言问答有 en01 可演示。

仍有风险：
- 点击框是 shot 级，不是逐帧；同一 shot 内角色走动时可能点偏。官方“所有可见帧都能点”严格验收会扣分。
- p01 封面只是 0–0.001s 元数据段，画面里没有封面原图。

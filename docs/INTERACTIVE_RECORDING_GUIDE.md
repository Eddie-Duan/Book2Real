## 1. 一次性准备

### 1.1 拉代码

    git clone git@github.com:Eddie-Duan/Book2Real.git
    cd Book2Real
    git checkout feat/skills-tuning

### 1.2 放交接包

把两个 zip 解压到仓库根，解压后应该是：

    runs/cn01/seedance_film/<stamp>/film.mp4
    runs/cn01/seedance_film/<stamp>/timeline.json
    runs/en01/seedance_film/<stamp>/film.mp4
    runs/en01/seedance_film/<stamp>/timeline.json
    books/cn01/click_targets.json
    books/en01/click_targets.json

zip 里已经按这个路径打好了，直接“解压到当前文件夹”即可。

### 1.3 配 .env（语音问答才需要）

    cp .env.example .env
    python scripts/setup_env.py

至少填 MINIMAX_API_KEY；不配也能录点击/检索/描述，但录不了语音问答。

### 1.4 起阅读器服务

    $env:B2R_FILM_SEEDANCE="1"
    python -m book2real reader --books books --port 8796

浏览器打开：

    http://127.0.0.1:8796/film?book=cn01
    http://127.0.0.1:8796/film?book=en01

**必须带 B2R_FILM_SEEDANCE=1**；不带会读旧 2.5D 片。

## 2. 录之前先自测（2 分钟）

en01 页面自测：

任何一项不通过，先别录，按第 6 节排查。

## 3. 录屏还是别人拍？

**录屏，不用真人出镜，也不用别人拍。**

官方 Q39 原话：“带交互版交操作录屏即可，不需另给可交互入口。”

推荐：
- Windows 自带：Win + G → 捕获浏览器窗口 + 系统声音 + 麦克风。
- 或 OBS：显示器/窗口捕获 + 桌面音频 + 麦克风；1080p / 30fps；输出 mp4。
- 不要用手机拍屏幕；不要露脸；不要后期剪辑。

录屏里必须能看见：
- 鼠标/触控点在哪里；
- 视频暂停、右侧介绍卡；
- 搜索/查字后画面跳转和框；
- 语音问完后 2 秒内开始回答（系统声音要录进去）。

## 7. 常见问题

| 现象 | 原因/处理 |
|---|---|
| /film 404 或回到旧片 | 没设 B2R_FILM_SEEDANCE=1；或端口连到了 ui 不是 reader |
| 页面能开但没画面 | 交接包没解压到 runs/<id>/seedance_film/<stamp>/，或 film.mp4 不在 |
| 点元素没反应 | 当前时间不在该 shot；用第 2 节的时间点；或框是 shot 级，角色已走动 |
| 查字框很小 | 用了旧 timeline；用 feat/skills-tuning + 交接包里的 timeline |
| 语音没反应 | .env 没配 MINIMAX_API_KEY；浏览器没给麦克风权限；系统声音没录进 OBS |
| 录屏没声音 | OBS 只加了麦克风，没加“桌面音频”；或 Win+G 没开系统声音 |

## 8. 诚实预期：能达标吗？

能达标：
- 四能力（跳帧/点选/描述/查字）都有可演示路径；
- 点击→暂停→介绍流程完整；
- 语音首响 2 秒有实测基础（MiniMax ASR+TTS，P95≈1.07s）；
- 中英双语 + 跨语言问答有 en01 可演示。

仍有风险：
- 点击框是 shot 级，不是逐帧；同一 shot 内角色走动时可能点偏。官方“所有可见帧都能点”严格验收会扣分。
- p01 封面只是 0–0.001s 元数据段，画面里没有封面原图。
- en01 是 480p，且点击框是页级 fallback，精度比 cn01 弱。
- 语音音色是否“幼儿园老师”只能人听，ASR 不验音色。

结论：**录一版能演示、能讲清四能力；但“所有可见帧点击精度”这一项还不是满分。** 如果时间够，先补逐帧框再录；不够就先录这一版。

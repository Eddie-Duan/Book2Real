# 纸书智伴 | 赛题分析


## 1 要求 → 交付

| 任务书要求 | 工程要求 | 交付证据 |
| --- | --- | --- |
| OCR、VLM、文生故事、文生视频等多 Agent 协同 | ≥4 个职责隔离 Agent + 可观测 DAG + 单步重试/降级 | 架构图、run 日志、产物目录 |
| 从纸质书**与文字描述**出发 | 输入 = 书页图 + 创作意图（主题/教育目标）；意图影响改编，不篡改原书事实 | 输入界面、忠实度评测 |
| 自动生成**完整**互动绘本视频 | 全书覆盖、有头有尾、音画字幕齐全 | 成片、页面覆盖率 |
| 智能语音交互 | ASR→检索→LLM→TTS，支持打断/追问 | 语音演示、首响数据 |
| 视觉触控式万物识别 | 点选局部→识别→结合本页上下文回答 | 角色/物体/背景点击演示 |
| 基于样本与 Query 音频集 | 适配格式、批量跑、结果可导出 | 评测适配层、结果文件 |
| 决赛限时改造新绘本 + 实时问答 | 零样本快速适配、操作 SOP、断网降级 | 计时记录、降级演练 |
| 网页/平板 Demo + 实测数据 | 浏览器可访问、平板触控、指标可复现 | Demo、指标表、复现脚本 |
| 考察五项工程能力 | 每项有可指认的实现与数据 | 说明书 5–7 章对应 |

**交付物**：互动播放器 Demo、单本互动包、评估数据、说明书（≤20 页）、数据/模型来源清单与合规材料、现场 SOP 与录屏兜底。

## 2 概念口径

| 概念 | 本质 | 职责 | 口径 |
| --- | --- | --- | --- |
| OCR | 专用 CV，非大模型 | 全文转录 + 坐标 | 不用 VLM 做主力 OCR |
| VLM | 大模型 | 画面理解、局部识别、看图问答 | 认字归 OCR，懂画归 VLM |
| 文生故事 | LLM | 改编、补衔接、设互动点 | 产出是制片单，不是散文 |
| 分镜 | 结构化 JSON | 镜头/时长/台词/参考图 | 视频生成的执行输入 |
| 文生视频 | 扩散/DiT | 3–8 秒片段 | 只生成关键镜头，全片靠剪辑合成 |
| ASR / STT | 同一任务 | 音频→文本 | 合并为一个模块，不拆分 |
| TTS | ASR 逆任务 | 文本→语音 | 旁白、台词、回答播报 |
| Agent | 模型+工具+契约 | 独立评测、替换、降级 | 数量不是评分点，边界与隔离才是 |

**注意**：OCR 认字、VLM 懂画；故事 Agent 交付分镜而非文案；预训练+轻量微调，不从头训练。

## 3 链路

| 环节 | 首选 | 输出 | 预算（目标） | 降级 |
| --- | --- | --- | --- | --- |
| S1 采集预处理 | OpenCV 透视矫正/去反光 | 矫正页图 | 0.5–1.5 s/页 | 手动裁剪 |
| S2 文字与版面 | PaddleOCR + 页序 | 文本块+坐标 | 0.3–0.8 s/页 | 云 OCR |
| S3 画面与索引 | Qwen3-VL + 检测/分割 | 实体（框/描述/建议问题） | 2–5 s/页，可并行 | 仅 OCR 关键词 |
| S4 故事与分镜 | Qwen3 + JSON Schema | 故事 + 分镜 JSON | 5–15 s/本 | 模板改编 |
| S5 视觉生成 | 2.5D 运镜 + 关键镜头 I2V | 镜头片段 | 2–5 s/页；I2V 30–90 s/镜 | 纯静态图 |
| S6 声音合成 | CosyVoice + ffmpeg | 音轨 + 成片 | 0.5–2 s/页；合成 1–3 s/页 | Edge-TTS |
| S7 交互服务 | 流式 ASR + 索引 + LLM + 流式 TTS | 文本 + 语音 | 首响 ≤1.5 s，完整 ≤3 s | 预置问答 |

**视频取舍**：全片 T2V 在 20–30 页规模下时限、成本、一致性不可兼得。2.5D 保“完整、稳定、像原书”，I2V 做亮点。若细则对生成时长有硬要求，把生成镜头做成 4/8/12 镜可调档，并附耗时与一致性数据。

**交互索引**：生产阶段预存每页实体（bbox、描述、建议问题）；运行时点击坐标命中即答，未命中再裁剪+VLM；高频问答缓存。点击首响目标 ≤1 s。

## 4 选型与微调

| 模块 | 基线 | 备选 | 许可证 |
| --- | --- | --- | --- |
| OCR | PaddleOCR（PP-OCRv5） | 云 OCR、TrOCR、Tesseract | Apache-2.0 / MIT |
| VLM | Qwen3-VL-8B | Qwen2.5-VL、MiniCPM-V 4.x | 逐尺寸确认 |
| 故事/分镜 | Qwen3-8B | DeepSeek、闭源 API | 需 JSON 模式 |
| 文生图 | SDXL、FLUX.1-schnell | Qwen-Image、即梦 API | FLUX.1-dev 非商用 |
| 文生视频 | Wan2.x I2V | HunyuanVideo、CogVideoX、可灵 | 逐项复核 |
| ASR | FunASR / SenseVoice-Small | Whisper-large-v3 | 代码 MIT，模型另确认 |
| TTS | CosyVoice 2 | IndexTTS-2、Edge-TTS | Apache-2.0，音色需授权 |
| 编排 | 自研 DAG / LangGraph | 任务队列 + 缓存 | 要可重跑、可观测 |
| 安全 | 敏感词 + 开源审核模型 | 云内容安全 | 输入/输出双审 |

**微调**：OCR 识别头（自摄 2–5k 行）；故事 LoRA（500–2k 改编样本）；VLM QLoRA（可选）；角色/画风 LoRA（每角色 20–50 张）。不训基座，TTS 不训。

**合规红线**：组委会样本只用于评测/演示，不训练；微调数据用公版/自摄/授权；童声需监护人授权、赛后删除；生成内容按《人工智能生成合成内容标识办法》标识；不使用隐藏测试集与标准答案。

## 5 难点与验收

| 难点 | 对策 | 验收 |
| --- | --- | --- |
| 角色/画风一致性 | 角色卡 + 参考图 + IP-Adapter/LoRA + 固定 seed + 挑片 | 跨页一致率 ≥80% |
| 页间叙事连贯 | StoryBible + 分镜 Schema + 状态校验 + 先大纲后逐页 | 完整率 100%，事实冲突 ≤1/本 |
| 视频成本与时长 | 2.5D + 关键 I2V、480p 草稿、并行、重试上限 | P1 ≤15 min，单本成本可封顶 |
| 语音时延 | 流式 ASR + VAD、LLM 限长、流式 TTS、预合成 | 首响 P95 ≤1.5 s |
| 触控识别 | 预建索引 + 命中测试 + 裁剪/VLM 兜底 + 高亮反馈 | Top-1 ≥80%，首字 ≤1 s |
| 童声/口语 | 童声实测、热词、澄清追问、指代消解 | CER ≤10%，澄清后完成率 ≥90% |
| 内容安全 | 双审、拒答模板、AI 标识、日志、家长开关 | 拦截 ≥95%，误杀 ≤5% |
| 现场不确定 | 本地优先、离线包、双网络、设备彩排、一键降级 | 断网仍可演示，降级 ≤60 s |

## 6 评测

| 指标 | 目标（待实测校准） |
| --- | --- |
| OCR 字符准确率 | 扫描 ≥95%，拍照 ≥90% |
| ASR CER（童声） | ≤10% |
| 故事忠实/适龄/连贯（人工 1–5） | 各 ≥4.0 |
| 页面覆盖率 | 100% |
| 角色一致性 | ≥80% |
| 问答准确率 / 幻觉率 | ≥85% / ≤5% |
| 改造成功率 | ≥95% |
| 单本耗时（P1） | 中位 ≤15 min |
| 语音/点击首响 P95 | ≤1.5 s / ≤1 s |
| 安全拦截/误杀 | ≥95% / ≤5% |

**方法**：组委会样本主评测；8–12 本公版/授权绘本作留出集，不参与调参；双人盲评、分歧第三人裁决；对比基线（无微调/纯 2.5D/纯 VLM OCR）+ 消融；每项标 n 与测试环境；记录失败案例并复测。

## 7 现场

| 动作 | 检查点 |
| --- | --- |
| 拍书/导入、页序、质检 | 无缺页、无模糊 |
| OCR + 索引 + 故事分镜 | 覆盖率、JSON 校验 |
| 视觉生成（并行）+ TTS | 镜头完成率、重试清单 |
| 合成、字幕、抽检 | 可播、音画同步 |
| 交互联调、彩排 | 语音/点击各 3 次成功 |

## 8 风险

| 风险 | 后果 | 对策 |
| --- | --- | --- |
| VLM 当主力 OCR | 字符幻觉被追问 | OCR 认字、VLM 懂画 |
| 宣称从头训练 | 可信度受损 | 统一“预训练+轻量微调” |
| ASR/STT 拆两个模块 | 概念错误 | 合并 ASR，TTS 单列 |
| 只证明记住固定绘本 | 决赛翻车 | 留出集证明泛化 |
| 无容错 | 单点崩全链路 | 每步重试/降级 |
| 承诺全片 T2V | 超时、角色崩坏 | 混合方案，主动说明取舍 |
| 多 Agent 只是多 prompt | 被质疑套壳 | 契约、独立模型、失败隔离 |
| 依赖公网/未审未标识 | 现场失败或合规扣分 | 离线包、双审、AI 标识 |
